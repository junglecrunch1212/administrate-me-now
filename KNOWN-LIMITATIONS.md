# Known limitations

These are bounded live limitations, not hidden pass claims. The former cron and
bridge-enrollment code blockers are closed in the release candidate; independent
review, merge, and disposable-Mac live evidence still gate family deployment.
None authorizes bypassing authorization, encryption, observation mode, or
backup safety.

| Limitation | Impact | Workaround | Planned resolution |
|---|---|---|---|
| GitHub still reports 78 Dependabot alerts against the unmerged default branch, including one critical alert in the retired `console/package-lock.json`. | The banner does not evaluate this PR's replacement locks/deletions; both fresh release-candidate Python environments and the retained OpenClaw package audit with zero known vulnerabilities. | Review the dependency diff and the clean-install audit evidence; do not deploy `main` before this PR is merged. | After merge, let GitHub recalculate the default branch, close alerts removed by the retired console and replacement locks, and triage any residual non-release manifests separately. |
| Real OpenClaw model/channel credentials and deep Gateway RPC cannot be exercised in credential-free CI. | Member chat correctly stays unavailable until a real provider probe succeeds; the eight deterministic household views continue to work. | After independent review and merge, run `./bootstrap/activate-openclaw.sh` only in the server Terminal. It delegates credentials to OpenClaw, validates config, probes the model, writes only a non-secret marker, reconciles cron, and restarts both services. | Record the disposable-Mac live gate, then repeat the exact activation on the family Mac. |
| Apple privacy grants, OAuth consent, Tailscale identity headers, and provider watermarks require human/provider UI. | Calendar, Reminders, Contacts, Notes, Gmail, Plaid, Home Assistant, and bridge capabilities remain disabled or degraded until explicitly granted. | Enable one integration at a time while observation mode is on; deny once first to verify graceful degradation; run Doctor after each grant. | Retain the post-merge signed activation checklist and provider-specific evidence outside the repository. |
| The deterministic browser harness ran in Microsoft Edge, not Safari with VoiceOver. | Authorization and accessible markup are automated, but Safari/VoiceOver focus order and announcements still need human confirmation. | Use the keyboard and VoiceOver checklist in `docs/operations/MAC-MINI-SETUP-READ-ALONG.md` before family rollout. | Capture a disposable-Mac Safari/VoiceOver report before the trust-period signoff. |
| OpenClaw `2026.7.2` exists at the reviewed GitHub commit but is not published as an npm release. | First install downloads and builds a verified roughly 95 MB source archive, so it is slower and requires reliable GitHub/package-registry access. | Use only `bootstrap/install.sh`; it verifies the pinned archive SHA-256, exact pnpm lock, package metadata, built version, and instance-local executable. Never substitute npm `latest` or a beta. | Move only after an independently reviewed stable OpenClaw release passes the complete compatibility and disposable-Mac gates. |
| Member enrollment now proves private transport, identity, revocation, and unattended LaunchAgent operation, but it enables no data pack by default. | Notes, Voice Memos, Obsidian, Calendar, and Reminders remain disabled after enrollment; the release does not claim a macOS privacy grant or live provider watermark. | Complete enrollment from the read-along, then leave packs off. Do not hand-edit bridge YAML; enable one pack only through a later reviewed configuration/grant flow. | Add an operator-safe per-pack configuration command and retain deny-then-grant live evidence for each Apple capability. |
| Clean-Mac CI proves credential-free launchd contracts, not long-duration idle resource use on the target Mac mini. | Pathological operations are bounded and local timings are measured, but week-long CPU, memory, and disk growth remain unknown. | Keep observation mode on, check Activity Monitor and disk growth daily during the five-to-seven-day trust period, and retain backups. | Add target-Mac telemetry thresholds after the first disposable-Mac soak without collecting household content. |
| Root and bridge Poetry builds emit migration warnings for legacy `[tool.poetry]` metadata. | No runtime or package reproducibility impact; lock and wheel builds pass. | None required. | Move static metadata to PEP 621 in a later packaging-only change. |
| CalDAV, Google Drive, optional channels, and other non-core providers remain deferred. | Those provider-specific conveniences are unavailable. | Use only retained, fully activated providers after independent review and merge. | Add each provider through a reviewed adapter pack and the full Cat-A–E contract. |

If a limitation would require bypassing observation, sharing a credential,
opening a non-Tailscale edge, changing the pinned OpenClaw version, or using a
member's identity for another member, stop and request a reviewed release.
