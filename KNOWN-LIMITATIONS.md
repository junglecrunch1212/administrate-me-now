# Known limitations

These are bounded live limitations, not hidden pass claims. Required GitHub CI and a protected merge govern code delivery. A clear, separate owner request plus the guarded deployment checks in ADR-0013 govern family deployment. None authorizes bypassing authorization, encryption, observation mode, backup, privacy, or provider-write safety.

| Limitation | Impact | Safe handling | Planned resolution |
|---|---|---|---|
| External dependency advisories can change without a source-code change. | A scheduled audit may discover a new advisory after deterministic CI passed. | Keep dependency audits advisory and scheduled; triage findings against the locked release before deployment. Never weaken deterministic tests to clear an external banner. | Update reviewed locks in an ordinary pull request when a relevant fix exists. |
| Real OpenClaw model/channel credentials and deep Gateway RPC cannot be exercised in credential-free CI. | Member chat stays unavailable until a real provider probe succeeds; deterministic household views continue to work. | After merge and a separate owner deployment request, use the guarded activation path. It delegates credentials to OpenClaw, validates configuration, probes the model, writes only a non-secret marker, reconciles cron, and restarts both services. | Prove the exact activation first in the disposable Mac lab, then use the same immutable release for family deployment. |
| Apple privacy grants, OAuth consent, Tailscale identity headers, and provider watermarks require human/provider UI. | Calendar, Reminders, Contacts, Notes, Gmail, Plaid, Home Assistant, and bridge capabilities remain disabled or degraded until explicitly granted. | Enable one integration at a time while observation mode is on; deny once first to verify graceful degradation; run Doctor after each grant. | Retain provider-specific evidence outside the repository. |
| Automated browser acceptance does not prove Safari with VoiceOver. | Authorization and accessible markup are automated, but Safari/VoiceOver focus order and announcements need human confirmation. | Use the keyboard and VoiceOver checklist in `docs/operations/MAC-MINI-SETUP-READ-ALONG.md` before family rollout. | Capture a disposable-Mac Safari/VoiceOver report before trust-period signoff. |
| OpenClaw `2026.7.2` is installed from a reviewed source commit rather than an npm release. | First install downloads and builds a verified source archive, so it is slower and needs reliable GitHub/package-registry access. | Use only `bootstrap/install.sh`; it verifies the pinned archive SHA-256, lock, package metadata, built version, and instance-local executable. Never substitute a floating release. | Move only after a stable OpenClaw release passes compatibility and disposable-Mac gates. |
| Member enrollment proves private transport, identity, revocation, and unattended LaunchAgent operation but enables no data pack by default. | Notes, Voice Memos, Obsidian, Calendar, and Reminders remain disabled after enrollment. | Complete enrollment, leave packs off, and never hand-edit bridge YAML. Enable a pack only through its configuration/grant flow. | Add an operator-safe per-pack command and retain deny-then-grant evidence for each Apple capability. |
| Clean-Mac CI does not prove week-long resource behavior on the target Mac mini. | Long-duration CPU, memory, and disk growth remain unknown. | Keep observation mode on and inspect resource/disk growth during the trust period while backups remain current. | Add thresholds after the first disposable-Mac soak without collecting household content. |
| Root and bridge Poetry builds emit migration warnings for legacy `[tool.poetry]` metadata. | Lock, wheel, and runtime reproducibility are unaffected. | No workaround is required. | Move static metadata to PEP 621 in a packaging-only change. |
| CalDAV, Google Drive, optional channels, and other non-core providers remain deferred. | Those provider-specific conveniences are unavailable. | Use only implemented and explicitly activated providers. | Add each provider through an ordinary adapter pull request and the full category contract. |

If a limitation would require bypassing observation, sharing a credential, opening a non-Tailscale edge, changing the pinned OpenClaw version, or using one member identity for another, stop and request the specific operational authority.
